# Resources and mapping

This page lists the courses, docs, and roadmaps behind the plan, and which weeks use each one. Daily lessons link to the exact docs page for that day. The courses are **optional extra depth**: watch the parts that match the week you're on, not the whole course up front.

**How links were checked:** every link is tested by `tools/check-links.mjs`, and the results are in `tools/link-report.json`. Udemy, Coursera, and LinkedIn Learning pages sometimes refuse automated checks, so a "blocked by site" result there doesn't mean the link is broken.

**Udemy Business note:** Udemy Business includes most popular Udemy courses, but not all of them. If a 🅤 course isn't in your company's catalog, search Udemy Business for its title or instructor.

**Access key:** 🆓 free · 🎓 Coursera Plus · 🅤 Udemy Business · 💼 LinkedIn Learning · 🧭 roadmap.sh Premium · 🅰 AlgoMaster Premium · ☁ AWS Skill Builder (free tier, with paid labs) · 🐶 Datadog Learning Center (free)

## Coverage map

| Goal | Weeks | What you'll have built |
|---|---|---|
| Linux and Ubuntu | 1–4 | Three WSL distros, an Ubuntu Server VM, systemd services, scripts, and a one-command deploy |
| Docker | 5–7 | Small, non-root, scanned, multi-architecture images and a Compose stack |
| Caching in .NET | 8–10 | IMemoryCache, output and HTTP caching, IDistributedCache, and HybridCache, with measurements |
| Distributed caching | 9–10, 22 | Valkey locally, then ElastiCache Serverless |
| NoSQL | 11–14 | Valkey data structures, MongoDB (modeling, aggregation, replica sets), and DynamoDB |
| Telemetry | 15–16, 20 | OpenTelemetry in .NET, the Collector, Prometheus, Grafana, Jaeger, and Loki |
| Kubernetes | 17–20 | StudyHub on kind with Helm, Gateway API, autoscaling, RBAC, and network policies |
| EKS | 21–23 | Auto Mode, ECR, Pod Identity, a load balancer, upgrades, and CI/CD |
| Datadog | 24–25 | Agent on Linux, Docker, and Kubernetes; APM; dashboards; monitors; and an SLO |
| StudyHub | 3–26 | Your portfolio project |
